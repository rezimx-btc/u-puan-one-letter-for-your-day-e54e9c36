## The entry

- **Letter:** `Z`
- **Hidden word:** zero sleep
- **Why it fits the brief:** Z is the only letter that is itself a word-symbol — "Zzz" is the universal shorthand for sleep. The judge only sees the letter, and Z instantly reads as sleep, or rather the lack of it: zero sleep. It is vivid (everyone pictures the Zzz), funny (running on empty is the most relatable day there is), and true (a day with zero sleep is a day everyone has lived). It needs no day of the week, no generic adjective, and no explanation — the letter does all the work.
